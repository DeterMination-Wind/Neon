# 战场观察

这一类功能专注于解决“看不清局面”的问题：将电力、物流、单位、投影与威胁信息直接叠加到游戏画面中，减少界面切换与误判。全部效果均为本地渲染，不影响其他玩家。

## 电网小地图（Power Grid Minimap）

将电力网络的结构与运行状态直接绘制在小地图和全屏地图上：

- 每张独立电网使用不同颜色区分，断网与跨网误接一目了然。
- 在电网中心显示净电力盈亏，字号、颜色与透明度均可调节。
- 当大电网分裂并出现负电时，自动标出可能的重新连接位置。
- 「电力表」悬浮窗口汇总各大电网的当前盈亏与近期最低值，帮助你快速定位最危险的电网。
- 缺电救援建议（Beta）可提示正电岛隔离方案以及需要暂时停用的冲击反应堆。

该功能的定位是快速回答“哪张网出了问题、该去哪里排查”，并不替代原版电力界面。支持客户端指令（默认前缀 `neon`，详见指令提示），在 MindustryX 环境下提供 X 变体增强。

## 偷袭小道（Stealth Path）

> [!NOTE]
> 该功能因当前版本存在已知缺陷而**默认关闭**，需要时请在 Neon 设置中手动开启。

根据地图威胁分布估算单位路线并绘制在世界中，便于规划比正面强攻更安全的走法：

- 支持切换路线模式，并按陆军、空军或全部威胁进行过滤。
- 自动模式可将单位集群引导至鼠标位置或聊天坐标，配合快捷键让单位沿规划路线移动。
- 在 MindustryX 或兼容的 OverlayUI 环境中提供信息悬浮窗口，展示模式、预计伤害与控制信息。
- 路线宽度、透明度与显示时长均可调整，并附带 `sp` 客户端指令。

## 增强小地图（betterMiniMap）

提升小地图的战场信息密度：

- 叠加显示单位与建筑图标，支持调整朝向、缩放、透明度与聚合间距。
- 支持分别显示或隐藏敌我双方的单位与建筑。
- 单位与建筑均配有可搜索的筛选对话框，支持全选、清空与反选。

适合在密集战场或大军团对局中快速辨识敌我动向。

## 投影叠加（Better Projector Overlay）

在放置超速投影前提前预判电力账目：

- 显示放置后的电网正负预判圈与实时数值提示。
- 扫描并标记被高布或穹顶覆盖的冗余普通超速投影，支持开启聊天提醒。
- 在 MindustryX 环境下提供 X 变体增强。

## 物流速率增强（betterLogisticsSpeed）

原版物流瞬时数值波动较大，本功能为建筑物流面板补充移动平均吞吐量：

- 可开启总吞吐量行，统计窗口时长与小数位数均可自定义。
- 判断长期产能适合用较长窗口（数值更稳），紧盯即时变化适合用较短窗口（反馈更快）。算法原理见 [术语表](../glossary.md#移动平均moving-average)。

## 地理围栏报警（Tripwire）

在地图中划定警戒围栏，当指定类型的单位穿越时立即触发提醒：

- 支持 Toast、聊天消息与 marker 三种提醒方式。
- 围栏可同时显示在世界与小地图中，检测间隔、聊天合并窗口与颜色覆盖均可调节。
- 适用于基地入口预警、资源区监视与战线边界提醒。首次使用需先配置控制键（未配置时设置页会视为未启用）。

## 锁定攻击（LockAttack）

帮助你持续集火同一个敌方目标：

- 按默认快捷键 `L`（可在 `设置 → 控制` 修改）锁定鼠标指向的敌方单位或建筑：直控单位会持续瞄准，被选中的指挥单位会通过原版客户端命令路径收到一次性集火指令（单机与联机均可用）。
- 指向新目标再按锁定键即可切换；点击空地或己方目标解锁；目标被摧毁后自动解锁。
- 支持开启锁定框、目标连线与目标血条。
