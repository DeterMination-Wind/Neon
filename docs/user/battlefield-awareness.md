# 战场观察

这一类功能解决"看不清"：电力、物流、单位、威胁等信息直接叠加到画面上，减少切界面和误判。全部为本地渲染，不影响其他玩家。

## 电网小地图（Power Grid Minimap）

把电力网络结构与状态画在小地图/全屏地图上。

- 每张独立电网一种颜色——断网、跨网误接一眼可见。
- 网中心显示净盈亏数字（字号/颜色/透明度可调）。
- 大电网分裂并出现负电时，标出可能的重新连接位置。
- "电力表"窗口列出各大电网当前盈亏与近期最低值，快速定位最危险的那张网。
- 缺电救援建议（Beta）可提示正电岛隔离和暂时停用冲击反应堆。

定位是"哪张网出了问题、去哪里检查"，不替代原版电力界面。支持客户端指令（默认前缀 `neon`，见指令提示）；在 MindustryX 环境下有 X 变体增强。

## 偷袭小道（Stealth Path）⚠ 默认关闭

按地图威胁估算单位路线并画出来，规划比直接冲锋更安全的走法。

- 路线模式与过滤：陆军 / 空军 / 全部威胁。
- 自动模式可把单位集群送往鼠标位置或聊天坐标，配快捷键让单位沿路线移动。
- MindustryX/兼容环境有信息窗口：显示模式、伤害和控制信息。
- 线宽、透明度、显示时间可调；另有 `sp` 客户端指令。

**因已知缺陷默认关闭**，需要在 Neon 设置中手动开启后再用。

## 增强小地图（betterMiniMap）

提升小地图信息密度：

- 叠加单位/建筑图标，支持朝向、缩放、透明度和聚合间距调整。
- 敌我分开显示或隐藏。
- 单位与建筑各有可搜索筛选对话框（全选/清空/反选）。

适合密集战场或大军团对局中快速辨析敌情。

## 投影叠加（Better Projector Overlay）

放置超速投影时提前算电力账：

- 显示放下后的电网正负预判圈与实时数值。
- 扫描标记被高布/穹顶覆盖的普通投影（放了也白放的），可选聊天提醒。
- MindustryX 环境有 X 变体增强。

## 物流速率增强（betterLogisticsSpeed）

原版物流瞬时值波动大，本功能给建筑物流面板加移动平均吞吐量：

- 可显示总吞吐行；统计窗口、小数位可调。
- 判长期产能用长窗口（稳），盯即时变化用短窗口（灵敏）。原理见[术语表](../glossary.md#移动平均moving-average)。

## 地理围栏报警（Tripwire）

在世界里画围栏，指定单位类型穿过就报警：

- 提醒方式：Toast / 聊天 / marker。
- 围栏可显示在世界与小地图上；检测间隔、聊天合并窗口、颜色覆盖可调。
- 典型用途：基地入口预警、资源区监视、战线边界提醒。首次使用需配置控制键（未配置时设置页视为未启用）。

## 锁定攻击（LockAttack）

持续集火一个目标：

- 按 `L`（默认，可在设置改）锁定鼠标指向的敌方单位/建筑：直控单位持续瞄准；被选中的指挥单位经原版命令路径收到一次性集火命令（单机联机都可用）。
- 再按锁新目标切换；点空地或己方解锁；目标死亡自动解锁。
- 锁定框、目标连线、目标血条可开。
