# 建造与操控

这一类功能专注于减少重复操作，让选方块、编队、下令与拆除都更加顺手。所有涉及单位命令的功能均走 Mindustry 原有客户端命令路径，联机可直接生效，无需服务器安装。

## 圆盘快捷建造（Radial Build Menu）

将常用方块放进径向 HUD，省去在建造栏中翻找的时间：

- **长按热键打开圆盘，松开即选中**，这是它与传统工具栏的核心区别。
- 最多支持 16 个槽位（内圈 8 槽 + 外圈 8 槽）。
- 支持多套槽位配置，并按时间、星球或自定义条件自动切换，也可通过 A/B 组热键手动切换。
- 半径、缩放、透明度、图标大小与展开方向均可自定义。
- 支持 JSON 导入/导出，方便备份与分享配置。

同时支持 `rbm` 客户端指令，在 MindustryX 环境下提供 X 变体。

## 更好的 RTS 编队（BetterRTSFormation）

改进编队的创建、选择与识别体验，同时保留原版快捷键习惯：

- 提供更清晰的编队角标。
- 支持严格编队选择，减少误选其他单位。
- 支持在非指挥模式下执行编队相关操作。

## 取消巡逻（Patrol Cancel）

解决“指挥单位仍处于巡逻姿态，导致普通移动或攻击命令不立即生效”的痛点：

- 右键指挥选中单位时自动清除巡逻状态，新命令立即生效。
- 中键排队与设置巡逻路线完全不受影响。

启用后即刻生效，无需额外学习成本。

## Poly 建造辅助（BetterPolyAi）

让 Poly 协助执行建造规划：

- 支持快捷键随时启停；仅执行**你自己的**建造与拆除计划，不会干涉其他玩家的规划。
- 建造目标间隔可调。该功能源自 MindustryX 的实现，在 Neon 中以纯客户端方式提供。

## 智能放置（Smart Placement）

专门解决混合科技地图中交叉物品运输线的高频误操作：

- 拖放交叉物品运输线时，满足条件即自动选用未配置的反向分拣器。
- 单科技星球、平行线路、端点以及非物品障碍物一律保持原版行为，只在明确场景下介入。
- 四类交叉（传送带 × 传送带、传送带 × 管道、管道 × 传送带、管道 × 管道）均可分别关闭；管道遇到 3 格及以上阻挡带时会整段改用物品管道桥。
- 反向分拣器只能连续串两个：当「传送带 × 管道」交叉会形成第 3 个时，保留已有两个，新线改用本科技的桥跨过整段交叉带（传送带线改用传送带桥，管道线改用物品管道桥），该规则可单独关闭。
- 默认仅在行星规则为「任意」的星球生效，也可在设置中关闭该限制。

## 智能拆除（AutoPruner）

> [!NOTE]
> 该功能在首次使用时**默认关闭**，以防不熟悉规则时误删建筑；在 Neon 设置中开启后会保留你的配置。

用于批量清理临时或冗余建筑：

- `J`：按电网连通性拆除多余电力节点——将电网（含相邻供电与连线）视为图结构，保留维持连通所需的最少骨架并清理冗余节点；塞尔普洛电力节点与埃瑞克光束节点均适用，本队与 `derelict` 中立电网均可清理，敌对建筑不会被加入拆除队列。
- `K`：按建筑放置时间窗口批量拆除建筑。

使用 `K` 前请确认时间窗口的覆盖范围，该操作会拆除窗口内的所有己方建筑。

## 快捷键增强（betterHotKey）

扩展原版输入配置，适合高频操作玩家：

- 支持双键组合热键与分组配置。
- 可处理地形编号冲突，并可选择是否保留被禁用建筑的槽位。
- 提供可视化配置界面，无需手动编辑配置文件；在 MindustryX 环境下提供 X 变体。

它与原版按键设置互不冲突：原版单键行为保持不变，仅在需要组合键或分组配置时使用。

## 建造透视（Build X-ray）

在建造、拆除或规划时，将被建造预览遮挡的内容变为半透明，便于精准对准目标位置：

- 放置、拆除、框选蓝图或拖拽重建选择时，预览范围内的单位、子弹与特效会平滑渐隐，停止操作后渐显恢复。
- 鼠标周围始终保留一块透明圆形区域，半径可在 8–64 格间调节。
- 「透视遮罩的透明度」支持 0%–100% 调节，默认为 80% 透明度、32 格半径。
- 建筑与地板不参与透明处理，确保放置预览本身始终清晰。

该功能为纯客户端显示效果，不改变建造合法性，也不发送任何网络请求。首次使用默认开启，可在 Neon 设置中关闭。

来源说明：玩法逻辑源自 Miner 的脚本模组 build-xray，Neon 负责 Java 移植与设置接入。
