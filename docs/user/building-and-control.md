# 建造与操控

这一类功能减少重复操作：选方块、编队、下令、拆除都更顺手。涉及单位命令的部分全部走 Mindustry 原有客户端命令路径，联机可用且服务器无需安装。

## 圆盘快捷建造（Radial Build Menu）

把常用方块放进径向 HUD：

- **长按热键打开圆盘，松开即选中**——这是它和普通工具栏最大的区别。
- 最多 16 槽：内圈 8 + 外圈 8。
- 多套槽位配置按时间/星球/自定义条件自动切换；A/B 组热键切换。
- 外观可调：半径、缩放、透明度、图标大小、方向。
- 配置 JSON 导入导出，方便备份分享。

另支持 `rbm` 客户端指令；MindustryX 环境有 X 变体。

## 更好的 RTS 编队（BetterRTSFormation）

改进编队的创建、选择和识别，同时保留原版快捷键习惯：

- 更清晰的编队角标；
- 严格编队选择，减少误选其他单位；
- 支持在非指挥模式下做编队相关操作。

## 取消巡逻（Patrol Cancel）

解决"指挥单位还挂在巡逻姿态上，普通移动/攻击命令不生效"的问题：

- 右键指挥选中单位时自动清巡逻状态，命令立即生效。
- 中键排队、设置巡逻路线不受影响。

装上即生效，无学习成本。

## Poly 建造辅助（BetterPolyAi）

让 Poly 帮你执行建造规划：

- 快捷键启停；只执行**你自己的**建造/拆除计划，不碰其他玩家的。
- 建造目标间隔可调。源自 MindustryX 的实现，作为客户端功能提供。

## 智能放置（Smart Placement）

处理混合科技地图交叉运输线的一个高频误操作：

- 拖放交叉物品线时，符合条件就自动选未配置的反向分拣器。
- 单科技星球、平行线路、端点、非物品障碍一律保持原版行为——只在明确场景介入。

## 智能拆除（AutoPruner）⚠ 默认关闭

批量清理临时/冗余建筑：

- 独立快捷键拆多余电力节点；
- 按建筑放置时间窗口批量拆除。

**首次使用默认关闭**，避免误删；在 Neon 设置中开启后沿用你自己的配置。拆之前想清楚时间窗口覆盖范围。

## 快捷键增强（betterHotKey)

扩展原版输入配置，适合重操作流玩家：

- 双键组合热键与分组配置；
- 处理地形编号冲突，可选保留被禁用建筑的槽位；
- 提供可视化配置界面，不必手改文件。MindustryX 环境有 X 变体。

与原版快捷键设置的分工：原版单键行为不动，需要组合键/分组才用它。
