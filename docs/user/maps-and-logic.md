# 地图与逻辑

本页涵盖制图、逻辑排错与数据审查类工具。这些功能全部运行在地图编辑器或本地界面中，对联机对战无任何影响。

## 地图编辑增强（betterMapEditor）

为地图生成器增加可自由拖动的镜像轴：

- 在生成器预览中直接拖动镜像轴，实时调整对称位置。
- 以可拖动镜像滤镜替代固定操作，不改变原有地图生成流程。

非常适合制作对称地图，尤其是双方镜像对抗图。

## 高级替换（AdvancedReplace）

扩展地图编辑器的染色地形工具：

- 提供三种模式：同色染色墙填充、染色地板填充与染色墙画笔。
- 基于 CIEDE2000 色差公式匹配颜色：容忍度越低，匹配越严格、误替换越少；容忍度越高，覆盖的视觉近似色越广。原理见 [术语表](../glossary.md#ciede2000δe00)。

适合处理由多种近似色构成的染色地图，省去逐格手动替换的繁琐操作。

## 自然地形生成（BetterTerrainGen-V2）

为地图地形生成器新增 Natural Water（自然水体）滤镜。该模块没有独立设置项，直接在生成器滤镜列表中选用即可。

## LogicSugar

让 Mindustry 逻辑编辑更接近结构化代码：

- 提供结构化逻辑语句、编辑器替换与编译辅助。
- 保留跳转线着色与积木颜色设置。
- 当 `call` 未填写实参时，显示被调用函数的参数占位提示，并随函数名与参数变化实时更新。
- 提供数据结构卡：支持将内存块区间声明为 `array`、`matrix`、`record`、`stack`、`queue`、`deque`、`bitset`、`map`、`uset`、`list`、`heap`、`chain`，每种结构配有独立操作卡；表达式中可直接书写 `buf[i]`、`m.get(k)` 进行读写，编译后全部降级为原版指令。
- 内置「断言」分类八张卡片、处理器状态指示与单位 flag 显示。
- 支持撤销/重做（桌面端 `Ctrl+Z` / `Ctrl+Y`，移动端底部按钮）、底栏按窗口宽度自动换行，以及编译后指令数与上限的实时对照。

它的目标是降低大型逻辑程序的阅读与维护成本，不改变处理器本身的运行规则。

## 谁在用这个建筑（WhoUsesThisBuilding）

逻辑排错的高效反向查询工具：

- 按住快捷键悬停在建筑上，即可反向高亮所有引用该建筑的逻辑处理器。
- 高亮标签格式为 `Lxx(opcode)`，直接指出逻辑行号与指令类型。
- 同时覆盖显式处理器链接与 `getblock(x,y)` 坐标式间接引用（详见 [术语表](../glossary.md#getblockxy-引用)）。

在大型逻辑地图中，比逐个打开处理器搜索建筑名高效得多。

## 补丁查看器（PatchViewer）

用于审查 datapatch 究竟修改了哪些游戏数据：

- 在数据库界面中内联展示补丁生效前后的内容对比。
- 对新增、删除与修改的属性进行高亮区分。
- 支持自定义高亮配色。聚焦“数据最终变成了什么”，非常适合排查内容包冲突。

## 隐藏处理器显示（Hide What Processors Show）

用于临时减轻画面视觉干扰：提供两个独立快捷键，分别隐藏世界处理器特效与动态 Marker。仅影响本地客户端渲染，不改动地图逻辑，非常适合录制视频或截图前清屏。
