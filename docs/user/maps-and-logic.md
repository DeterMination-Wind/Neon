# 地图与逻辑

制图、逻辑排错和数据审查类工具。这一页的功能都发生在编辑器或本地界面里，对联机对战零影响。

## 地图编辑增强（betterMapEditor）

给地图生成器加可拖动的镜像轴：

- 在生成器预览中直接拖动镜像轴调整对称位置。
- 用可拖动镜像滤镜替代固定操作，不改变原有生成流程。

对称地图（尤其是双方镜像对抗图）的必装体验。

## 高级替换（AdvancedReplace）

扩展编辑器的染色地形工具：

- 三种模式：同色染色墙填充、染色地板填充、染色墙画笔。
- 颜色匹配用 CIEDE2000 色差公式：容忍度低→匹配严格误替换少；容忍度高→覆盖更多视觉近似色。原理见[术语表](../glossary.md#ciede2000δe00)。

适合处理由多个近似颜色组成的染色图，省掉逐块手换。

## 自然地形生成（BetterTerrainGen-V2）

为地形生成器增加 Natural Water（自然水体）滤镜。没有独立设置组；在生成器滤镜里直接选用即可。

## LogicSugar

让 Mindustry 逻辑更像结构化代码：

- 结构化逻辑语句、编辑器替换与编译辅助；
- 保留跳转线着色和积木颜色；
- `call` 未填实参时显示被调用函数的参数占位提示，随函数名/参数实时更新。

目标是降低大逻辑程序的阅读维护成本，不改变处理器的运行规则。

## 谁在用这个建筑（WhoUsesThisBuilding）

逻辑排错的反向查询神器：

- 按住快捷键悬停建筑 → 反向高亮所有引用它的逻辑处理器。
- 标签形如 `Lxx(opcode)`：直接给出逻辑行号与指令类型。
- 同时覆盖显式处理器链接与 `getblock(x,y)` 坐标式间接引用（见[术语表](../glossary.md#getblockxy-引用)）。

大型逻辑图里比逐个打开处理器搜索名字快得多。

## 补丁查看器（PatchViewer）

审查 datapatch 实际改了什么：

- 在数据库界面内联显示补丁前后的内容；
- 新增/删除/修改属性高亮区分；
- 颜色设置可调。关注"数据最终变成了什么"，适合排查内容包冲突。

## 隐藏处理器显示（Hide What Processors Show）

画面减负：两个独立快捷键分别隐藏世界处理器特效与动态 Marker。只改客户端渲染，不动地图逻辑——录视频或截图前清屏很好用。
