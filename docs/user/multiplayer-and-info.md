# 联机与信息

联机辅助与本地信息管理。注意本页两个涉及数据/隐私的功能边界：玩家数据库只存本地，翻译功能会把文本发给第三方服务。

## 玩家数据库（ServerPlayerDataBase）

在**你自己客户端**记录长期联机需要查询的上下文：

- 记录玩家名称、UID、服务器，以及可用的 IP 追踪结果。
- 可选聊天日志；支持导入、导出、完整性校验和异常提示。
- 有 OverlayUI 的环境提供查询/调试窗口，没有时回退普通对话框。
- 数据存储用本地 SQLite；另有嵌入向量模型支撑的语义搜索（打包时才下载模型）。

⚠ 隐私边界：所有数据保存在客户端本地。遵守服务器规则和当地隐私法规，不要把本地记录当作公开资料传播。

## 自定义标记（customMarker）

把聊天坐标和想记录的位置变成好用的地图标记：

- 流程：按钮 → 全屏点位 → 面板确认，减少地图和聊天间来回切换。
- 5 组可编辑模板，消息格式 `<内容><内容>(x,y)`。
- 聊天坐标捕获窗口：从聊天记录里选坐标快速聚焦。
- MindustryX 环境接入其标记能力（经标记桥）。

## 外语服务器翻译（ForeignServerTranslator）

跨语言联机辅助，不永久改写服务器内容：

- 标记外语服务器；收发聊天和服务器文本辅助翻译。
- 引擎：Microsoft Translator 或 OpenAI 兼容接口，均可配自定义地址。
- 可启用 Mindustry bundle 术语提示——方块、单位、物品名按游戏原文翻译。
- 配置统一放 Neon 设置。

⚠ 第三方服务可见性：请求会经过你配置的翻译服务商，配置前确认其隐私政策。

## 模组更新中心（modUpdater）

一个界面管所有 mod 的更新：

- 启动检查 GitHub Release；列表区分 可更新 / 已最新 / 黑名单 / 无仓库。
- 单个或批量更新。
- 仓库覆盖（repo 字段缺失的 mod 手工指定）、黑名单、镜像下载切换。

聚合包的更新入口只有这一个，各子模组不会再单独弹更新提示。技术细节见[更新中心](../subsystems/modupdater.md)。

## 拼音搜索支持（PinyinSearchSupport)

中文玩家的搜索补全：

- 搜索框输入完整拼音、模糊拼音或首字母即可匹配中文条目；
- 支持多音字与中英数字混合输入；
- 搜索延迟可调（即时反馈 vs 大列表性能）。生效范围由场景作用域控制并有回归测试保护。
