# 联机与信息

本页涵盖联机辅助与本地信息管理工具。使用前请留意两项数据与隐私边界：玩家数据库仅保存在客户端本地，而外语服务器翻译会将待翻译文本发送至第三方翻译服务。

## 玩家数据库（ServerPlayerDataBase）

在**你的本地客户端**记录长期联机所需的查询上下文：

- 记录玩家名称、UID、服务器信息以及可用的 IP 追踪结果。
- 可选保存聊天日志，支持导入/导出、完整性校验与异常提示。
- 在具备 OverlayUI 的环境中提供查询与调试悬浮窗口，否则自动回退为普通对话框。
- 底层使用本地 SQLite 存储，并支持基于嵌入向量模型的语义搜索（仅在打包时按需下载模型）。

> [!WARNING]
> **隐私边界**：所有数据均保存在客户端本地。请遵守服务器规则与当地隐私法规，切勿将本地记录当作公开资料随意传播。

## 自定义标记（customMarker）

将聊天坐标与想记录的位置转化为直观的地图标记：

- 采用“按钮 → 全屏点位 → 面板确认”的交互流程，减少在地图与聊天界面间来回切换。
- 提供 5 组可编辑标记模板，消息格式为 `<内容><内容>(x,y)`。
- 内置聊天坐标捕获窗口，可直接从聊天记录中点选坐标并快速聚焦。
- 在 MindustryX 环境下通过标记桥接入其原生标记能力。

## 外语服务器翻译（ForeignServerTranslator）

提供跨语言联机辅助，不会永久改写服务器内容：

- 支持标记外语服务器，辅助翻译收发聊天与服务器文本。
- 支持 Microsoft Translator 与 OpenAI 兼容接口，均允许配置自定义服务端点。
- 可开启 Mindustry bundle 术语提示，让方块、单位与物品名称更贴合游戏官方译名。
- 所有配置均统一收拢在 Neon 设置中。

> [!WARNING]
> **第三方服务可见性**：翻译请求会发送至你配置的第三方服务商，填写凭据前请先确认对方的隐私政策。

## 模组更新中心（modUpdater）

在一个界面中集中管理所有模组的更新：

- 启动时检查 GitHub Release，并在列表中清晰区分「可更新」「已最新」「黑名单」「无仓库」四种状态。
- 支持单个更新与批量更新。
- 支持仓库覆盖（为缺少 `repo` 字段的模组手动指定仓库）、黑名单管理与镜像下载切换。

Neon 聚合版仅保留这一处更新入口，各子模组不再各自弹出更新提示。技术细节见 [更新中心子系统文档](../subsystems/modupdater.md)。

## 拼音搜索支持（PinyinSearchSupport）

面向中文玩家的搜索输入增强：

- 在搜索框中输入完整拼音、模糊拼音或首字母即可匹配中文条目。
- 支持多音字及中英数字混合输入。
- 支持调节搜索延迟，在即时反馈与大列表性能间灵活平衡。生效界面由场景作用域控制，并有回归测试保障。
