# 个性化与趣味

本页介绍视觉、输入与趣味类功能。这些功能均不影响游戏核心逻辑，可完全按个人喜好自由开关。

## Random（随机化）

为下一次进入世界增添一点意想不到的混乱感：

- 随机打乱数据库文本、战役与液体描述以及游戏内提示文案。
- 随机打乱方块、物品、单位与战役区块图标。
- 仅改变视觉与文本呈现，不影响任何游戏逻辑。

> [!NOTE]
> **特殊入口**：Random 没有独立的设置分组。如需体验，请在主菜单点击「千万别点」，下一次进入世界时即会生效。

## 导管染色（Color-the-ducts）

> [!NOTE]
> 该功能在首次使用时**默认关闭**，可在 Neon 设置中手动开启并调整参数。

让液体导管中的内容一目了然：

- 在液体导管中心绘制对应液体颜色的标记。
- 支持悬停模式与整条连接显示，缩放比例与透明度均可调节。
- 纯视觉叠加，不改变液体运输逻辑。

## 更好的截图（BetterScreenShot）

用于生成高分辨率世界截图，默认快捷键 `F8`（可在 `设置 → 控制` 修改），也可通过 Overlay 按钮启动：

- 对大地图采用分块渲染，突破单张纹理尺寸上限。
- 开始前可预估输出图片尺寸，渲染过程中实时显示进度。
- 非常适合保存地图全景、展示基地与制作攻略素材。

来源说明：BSS 核心代码源自 Miner，Neon 负责将其接入统一设置与界面。
