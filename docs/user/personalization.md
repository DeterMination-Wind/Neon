# 个性化与趣味

视觉、输入和趣味内容。这一页的功能不影响游戏逻辑，按个人喜好开关。

## Random（随机化）

给下一次进入世界加点混乱：

- 随机打乱数据库文本、战役和液体描述、游戏内提示；
- 随机打乱方块、物品、单位和战役区块图标；
- 不改变任何逻辑行为，纯视觉与文本。

**入口特殊**：没有设置组——在主菜单点击"千万别点"，下次进入世界生效。

## 导管染色（Color-the-ducts）⚠ 默认关闭

让导管里的液体一眼可辨：

- 在液体导管中心画对应液体颜色的标记。
- 悬停模式 / 整条连接显示；缩放、透明度可调。
- 纯视觉叠加，不改变运输逻辑。首次使用默认关闭，开启后在统一设置页调整。

## 更好的截图（BetterScreenShot）

高分辨率世界截图，默认快捷键 `F8`（可在设置改），也可从 Overlay 按钮启动：

- 大地图分块渲染，突破单张纹理尺寸限制；
- 开始前可预估输出尺寸，渲染中显示进度；
- 适合保存地图全景、基地展示和攻略素材。

来源说明：BSS 核心代码来自 Miner，Neon 负责接入统一设置与界面。
